# ZeroMusic releases

ZeroMusic is a free Android music player built by [Suraj Mavuleti](https://zero.skillissue.gg/). Website: [zero.skillissue.gg/zero-music](https://zero.skillissue.gg/zero-music).

Download the latest APK from [Releases](../../releases/latest) and open it on your Android phone (Android 8.0+).

Once installed, ZeroMusic checks this repo for new versions and offers to update itself.

## Website

`zero-music/` is the app's website (home page, privacy policy, terms), published with GitHub Pages and served at
[zero.skillissue.gg/zero-music](https://zero.skillissue.gg/zero-music) through a rewrite on the main site.
